# Social Network - Полнофункциональная социальная сеть

## 📋 Описание проекта

**Social Network** - это современная полнофункциональная социальная сеть, построенная с использованием микросервисной архитектуры. Проект включает в себя все основные функции, которые пользователи ожидают от социальной платформы: регистрация, аутентификация, создание постов, комментарии, лайки, дружба, подписки и уведомления.

### 🎯 Основные возможности

- **🔐 Аутентификация и авторизация**
  - Регистрация с подтверждением email
  - JWT токены с безопасными HTTP-only куками
  - Защищенные эндпоинты

- **👥 Профили пользователей**
  - Персональные профили с аватарами
  - Биография, дата рождения, страна
  - Статистика подписчиков и постов

- **📝 Посты и контент**
  - Создание постов с изображениями
  - Автоматическое создание превью изображений
  - Поддержка заголовков и текстового контента

- **💬 Комментарии**
  - Многоуровневые комментарии (треды)
  - Ответы на комментарии
  - Лайки на комментарии

- **❤️ Система лайков**
  - Лайки постов и комментариев
  - Счетчики лайков
  - История лайков пользователя

- **👫 Дружба**
  - Запросы на дружбу
  - Управление друзьями

- **📢 Подписки**
  - Подписка на пользователей
  - Лента подписок
  - Счетчики подписчиков

- **🔔 Уведомления**
  - Уведомления о новых постах, лайках, комментариях
  - Уведомления о подписках
  - Система прочтения уведомлений

- **🔍 Поиск**
  - Поиск пользователей через Elasticsearch
  - Быстрый и точный поиск

## 🛠 Технологический стек

### Backend (Django)
- **Framework**: Django + Django REST Framework
- **База данных**: SQLite (для разработки), поддержка PostgreSQL
- **Аутентификация**: JWT токены
- **Кэширование**: Redis
- **Очереди задач**: Celery
- **Поиск**: Elasticsearch
- **Документация API**: drf-spectacular (OpenAPI/Swagger)
- **Профилирование**: Django Silk
- **Изображения**: Pillow
- **Тестирование**: pytest
- **Линтинг**: Ruff

### Frontend (React)
- **Framework**: React
- **Сборщик**: Vite
- **Маршрутизация**: React Router DOM
- **Стилизация**: Tailwind CSS
- **HTTP клиент**: Axios
- **Формы**: React Hook Form + Yup
- **Линтинг**: ESLint

### DevOps & Инфраструктура
- **Контейнеризация**: Docker + Docker Compose
- **Веб-сервер**: Daphne (ASGI)
- **Мониторинг**: Django Silk для профилирования

## 🚀 Быстрый старт

### Предварительные требования

- Docker и Docker Compose
- Git

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd social_network
```

### 2. Настройка переменных окружения

Создайте файл `backend/.env`:

```bash
# Django
SECRET_KEY=your-secret-key-here
DEBUG=True

# Email (для подтверждения регистрации)
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_HOST_USER=your-email@gmail.com
EMAIL_HOST_PASSWORD=your-app-password

# Elasticsearch
ELASTICSEARCH_HOST=http://elasticsearch:9200
```

### 3. Запуск с помощью Docker Compose

```bash
# Сборка и запуск всех сервисов
docker-compose up --build
```

### 4. Выполнение миграций

```bash
# Выполнение миграций Django
python manage.py migrate

# Создание суперпользователя (опционально)
python manage.py createsuperuser
```

### 5. Создание индексов Elasticsearch

```bash
# Создание индексов для поиска
python manage.py search_index --create
```

### 6. Доступ к приложению

- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:8000
- **API Документация**: http://localhost:8000/api/schema/swagger-ui/
- **Elasticsearch**: http://localhost:9200
- **Redis**: localhost:6379

Для production развертывания рекомендуется:

1. Использовать PostgreSQL вместо SQLite
2. Настроить Nginx как обратный прокси
3. Использовать SSL сертификаты
4. Настроить мониторинг и логирование
5. Использовать CDN для статических файлов
6. Настроить бэкапы базы данных
